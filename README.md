## ออกเวอร์ชันใหม่ของเว็บ (ทุกครั้งก่อน push ที่แก้ marker/)
1. `.venv\Scripts\python tools/bump_version.py 0.8.1` → แก้ `marker/version.js` และ `?v=` ของทุกไฟล์ใน `marker/index.html`
2. รันเทสต์ + `tools/check_publish.py --list` แล้วค่อย push (GitHub ตรวจ `bump_version.py --check` อีกรอบก่อนเผยแพร่)
3. เว็บที่หมอเปิดอยู่ (รวมไอคอนบนหน้าจอโฮม) จะเช็ก `version.js` ตอนเปิด/กลับมาที่หน้าจอ แล้วบันทึกงานและโหลดเวอร์ชันใหม่เอง **ไม่ต้องลบไอคอน** (ลบไอคอน = งานในเครื่องหาย)

### ลองขั้น 4–5 เองบน Edge
1. เปิดแพ็กเกจ → ช่องเอกซเรย์ซูมพอดีกรอบเส้นประ · ลองปุ่ม "ดูทั้งภาพ" / "กลับไปที่กรอบ"
2. กด "ถัดไป" ไปถึง **T006** (งานสมจริง: ฟลูคือบริเวณในกรอบที่ขยาย) → มาร์ก 4 คู่ → "ถัดไป"
3. ลอง "มาร์กไม่ได้", วาง 3 คู่แล้วกด "ถัดไป" (ต้องเลือกเหตุผล), "ปรับภาพ" → กลับสีฟลู
4. **ปิดแท็บกลางงาน** แล้วเปิดใหม่ → หน้าแรกต้องแสดงงานที่ทำไว้ → เปิดแพ็กเกจ → ทำต่อจากงานเดิม
5. "ส่งออก" → ดาวน์โหลด JSON และ CSV (ไปที่โฟลเดอร์ Downloads) · เปิด CSV ดูหัวไฟล์ (#) และค่าพิกัด
6. ลองนำเข้า: F12 → Application → IndexedDB → ลบ `pelnav-marker` → รีเฟรช → หน้าแรกขึ้นกล่องเหลือง → "นำเข้าไฟล์สำรอง" เลือก JSON → ข้อมูลกลับมา
7. สำรอง: กด "มาร์กไม่ได้" สัก 2–3 งาน → ปิดแท็บโดยไม่กด "จบงาน" → เปิดใหม่ → หน้าแรกต้องมีกรอบแดง "ยังไม่ได้สำรองงานรอบก่อน" + ปุ่ม **สำรองทันที** · กด "จบงาน" → ต้องสำรองก่อนกลับหน้าแรก
8. ไฟล์ CSV/JSON ที่ส่งออกจากงานจริงห้ามขึ้น git (กันไว้ใน .gitignore แล้ว)

**อ่าน CSV ด้วย Python:** `pd.read_csv(path, comment='#', encoding='utf-8-sig')`

### ลองมาร์กจุดเองบน Edge (ขั้น 3)

ในแพ็กเกจทดสอบ กากบาทแต่ละอันมีตัวเลขกำกับ เช่น `1 (100,200)` = ตำแหน่งที่ถูกต้อง

1. **กดเมาส์ค้างไว้** ใกล้กากบาท ประมาณครึ่งวินาที → แว่นขยายวงกลมขึ้นที่มุมช่อง
2. **ค่อย ๆ ขยับเมาส์** (จุดจะขยับช้ากว่าเมาส์ 4 เท่า) จนกากบาทสีในแว่นอยู่ตรงกลางกากบาทขาวของภาพ → **ปล่อยเมาส์**
3. หัวช่องแสดง `เลือกจุด 1 (100.0, 200.0)` → เทียบกับเลขบนภาพ ต้องคลาดไม่เกิน ±1
4. แถบบนจะบอกให้วางจุด 1 บนอีกภาพ (ขอบช่องเป็นสีของจุด) → ทำต่อจนครบ 4 คู่
5. ลองอย่างอื่น: ลากจุดเดิม (กดบนจุดแล้วลาก) · คลิกจุดแล้วกด "ลบจุด" หรือปุ่ม Delete · "↶ ย้อน" หรือ Ctrl+Z · Esc ยกเลิกระหว่างวาง
6. ลองที่ซูมต่าง ๆ (ล้อเมาส์) — ซูม 1× ก็วางได้แม่นเพราะใช้แว่นขยาย
7. เปิด `bad_size_package` และ `bad_exif_package` → ต้องขึ้นหน้าต่างสีแดง "หยุด" และไม่แสดงภาพ

บน iPad: Apple Pencil แตะ/ลาก = วางจุด · นิ้ว = เลื่อน/ซูม · ถ้าไม่มี Pencil กด "นิ้ววางจุด: เปิด" แล้วกดนิ้วค้าง

**มาตรฐานพิกัด:** แบบ COCO — (0, 0) คือมุมซ้ายบนของพิกเซลแรก, กึ่งกลางพิกเซล (i, j) อยู่ที่ (i+0.5, j+0.5) · ใช้กับ OpenCV ให้ลบ 0.5 (รายละเอียดใน [DECISIONS.md](DECISIONS.md))

## สร้าง study package จากข้อมูลจริง

ข้อมูลจริงอยู่ในโฟลเดอร์ข้อมูลที่ซิงก์ลงเครื่อง — **อ่านอย่างเดียว ห้ามเขียนอะไรลงไป** · ตำแหน่งเก็บในไฟล์ `tools/data_root.txt` (1 บรรทัด อยู่ในเครื่องเท่านั้น ไม่ขึ้น git) · ผลลัพธ์เขียนในโปรเจกต์ (อยู่ใน .gitignore)

ตรวจโครงสร้าง COCO: `python -I -X utf8 -B tools/inspect_coco.py`

```powershell
# 1) ดูสรุปก่อน (dry-run ไม่เขียนอะไร)
python -I -X utf8 -B tools/make_study_package.py --pilot --cases เคสตัวอย่าง1,เคสตัวอย่าง2,เคสตัวอย่าง3 --k 2
# 2) สร้างจริง
python -I -X utf8 -B tools/make_study_package.py --pilot --cases เคสตัวอย่าง1,เคสตัวอย่าง2,เคสตัวอย่าง3 --k 2 --write
# ชุดทดสอบจริง 70 ราย จาก splits.csv (วางไว้ที่รากโปรเจกต์ · อยู่ใน .gitignore):
python -I -X utf8 -B tools/check_splits.py                                    # 1) ตรวจไฟล์แบ่งชุด (อ่านอย่างเดียว)
python -I -X utf8 -B tools/make_study_package.py --splits splits.csv --k 3    # 2) dry-run แล้วค่อยเติม --write
```
เคสที่ใช้ภาพฟลูไม่ได้เลย: `python -I -X utf8 -B tools/report_fluoro_missing.py` → `fluoro_missing_report.csv` (.gitignore) · ภาพ BMP ถูกแปลงเป็น PNG แบบไม่เสียคุณภาพ (ตรวจพิกเซล) · fluo_id ที่ลงท้าย flip/rotate (หมายเหตุของหมอ) จับคู่กับไฟล์ชื่อหลักหรือชื่อที่มีคำต่อท้าย ใช้ได้เมื่อรวมกันเจอภาพเดียวและภาพนั้นไม่มีกรอบอื่น · บันทึกใน key.csv คอลัมน์ `fluo_flag` (ไม่อยู่ใน manifest)

`check_splits.py` ตรวจ: ครบทุกเคสในโฟลเดอร์ข้อมูล · train/val/test เท่านั้น · test = 70 · ไม่มีชื่อ/HN · เคสที่สงสัยว่าเป็นผู้ป่วยคนเดียวกัน (`tools/same_patient_groups.txt` อยู่ในเครื่องเท่านั้น) อยู่ชุดเดียวกัน · เคส test มีกรอบใน instances_clean.json อย่างน้อย 1 กรอบ
ผลลัพธ์ (ทั้งหมดอยู่ใน .gitignore): `pilot_package/` (ให้แพทย์) · `pilot_key.csv` (ทีมเท่านั้น) · `pilot_report.csv` (ทุกกรอบ + สาเหตุที่ตัด) · `pilot_summary_by_case.csv` (นับสาเหตุที่ตัดแยกรายเคส) · `pilot_check/` (ภาพตรวจกรอบ — งานที่จับคู่ fluo_id แบบหลวมชื่อ `Txxx_LOOSE.jpg` ให้ดูด้วยตาก่อน)

### เปิด pilot_package บน Edge ในโน้ตบุ๊ก
1. `python tools/serve_lan.py --local` (เปิดเฉพาะในเครื่องนี้)
