# PelNavPlan Landmark Marker

เว็บให้ศัลยแพทย์มาร์กจุดอ้างอิง 4 คู่ บนภาพเอกซเรย์และภาพฟลูออโรสโคปี (ชุดทดสอบ 70 ราย) เพื่อใช้คำนวณ TRE/nTRE

- สเปก: [SPEC_marking_tool.md](SPEC_marking_tool.md) · การตัดสินใจเพิ่มเติม: [DECISIONS.md](DECISIONS.md)
- เว็บเป็นไฟล์ HTML/JS ล้วน ไม่มีเซิร์ฟเวอร์ **ภาพผู้ป่วยไม่ถูกส่งผ่านเครือข่าย**

## สถานะ

| ขั้น | เนื้อหา | สถานะ |
|---|---|---|
| 0 | โครงโฟลเดอร์ + ภาพทดสอบสังเคราะห์ | ✅ |
| 1 | เปิดแพ็กเกจ ตรวจ manifest/ไฟล์/ขนาด/EXIF | ✅ |
| 2 | ซูม/เลื่อน/รีเซ็ต + แสดงพิกัด | ✅ (รอทดสอบบน iPad จริง) |
| 3 | มาร์กจุด 1–4 ผ่านแว่นขยาย, ลากปรับ, ย้อน, ลบ | ✅ (รอทดสอบบน iPad จริง · ยังไม่บันทึกลงเครื่อง) |
| 4 | ซูมพอดีกรอบ, นำทาง, มาร์กไม่ได้/3 คู่, เวลา, ปรับภาพ, เตือนจุดกระจุก | ✅ (รอทดสอบบน iPad จริง) |
| 5 | บันทึกอัตโนมัติ, บังคับสำรองทุก 10 งาน, ส่งออก CSV/JSON, นำเข้า รวม/แทนที่ | ✅ (รอทดสอบบน iPad จริง) |
| 6 | `make_study_package.py` | ✅ (pilot ภาพจริง 6 งาน ทีมทดลองแล้ว กรอบตรงทุกงาน) |
| 7 | ทดสอบอัตโนมัติครบชุด | ✅ พิกัด + ขั้นตอนงาน + สร้างแพ็กเกจ |
| 8 | iPad จริง, GitHub Pages, ทดลองกับหมอ | 🟨 iPad รอบ 1 ผ่าน · เว็บขึ้นแล้ว https://witsarut17.github.io/landmark-marker/ · รอ iPad รอบ 2 |

### ลองขั้น 4–5 เองบน Edge
1. เปิดแพ็กเกจ → ช่องเอกซเรย์ซูมพอดีกรอบเส้นประ · ลองปุ่ม "ดูทั้งภาพ" / "กลับไปที่กรอบ"
2. กด "ถัดไป" ไปถึง **T006** (งานสมจริง: ฟลูคือบริเวณในกรอบที่ขยาย) → มาร์ก 4 คู่ → "ถัดไป"
3. ลอง "มาร์กไม่ได้", วาง 3 คู่แล้วกด "ถัดไป" (ต้องเลือกเหตุผล), "ปรับภาพ" → กลับสีฟลู
4. **ปิดแท็บกลางงาน** แล้วเปิดใหม่ → หน้าแรกต้องแสดงงานที่ทำไว้ → เปิดแพ็กเกจ → ทำต่อจากงานเดิม
5. "ส่งออก" → ดาวน์โหลด JSON และ CSV (ไปที่โฟลเดอร์ Downloads) · เปิด CSV ดูหัวไฟล์ (#) และค่าพิกัด
6. ลองนำเข้า: F12 → Application → IndexedDB → ลบ `pelnav-marker` → รีเฟรช → หน้าแรกขึ้นกล่องเหลือง → "นำเข้าไฟล์สำรอง" เลือก JSON → ข้อมูลกลับมา
7. บังคับสำรอง: เปิด `tests\generated\test_package_big` แล้วกด "มาร์กไม่ได้" 10 งาน → หน้าต่างสำรองต้องขึ้น
8. ไฟล์ CSV/JSON ที่ส่งออกจากงานจริงห้ามขึ้น git (กันไว้ใน .gitignore แล้ว)

**อ่าน CSV ด้วย Python:** `pd.read_csv(path, comment='#', encoding='utf-8-sig')`

### ลองมาร์กจุดเองบน Edge (ขั้น 3)

ในแพ็กเกจทดสอบ กากบาทแต่ละอันมีตัวเลขกำกับ เช่น `1 (100,200)` = ตำแหน่งที่ถูกต้อง

1. **กดเมาส์ค้างไว้** ใกล้กากบาท ประมาณครึ่งวินาที → แว่นขยายวงกลมขึ้นที่มุมช่อง
2. **ค่อย ๆ ขยับเมาส์** (จุดจะขยับช้ากว่าเมาส์ 4 เท่า) จนกากบาทสีในแว่นอยู่ตรงกลางกากบาทขาวของภาพ → **ปล่อยเมาส์**
3. หัวช่องแสดง `เลือกจุด 1 (100.0, 200.0)` → เทียบกับเลขบนภาพ ต้องคลาดไม่เกิน ±1
4. แถบบนจะบอกให้วางจุด 1 บนอีกภาพ (ขอบช่องเป็นสีของจุด) → ทำต่อจนครบ 4 คู่
5. ลองอย่างอื่น: ลากจุดเดิม (กดบนจุดแล้วลาก) · คลิกจุดแล้วกด "ลบจุด" หรือปุ่ม Delete · "↶ ย้อน" หรือ Ctrl+Z · Esc ยกเลิกระหว่างวาง
6. ลองที่ซูมต่าง ๆ (ล้อเมาส์) — ซูม 1× ก็วางได้แม่นเพราะใช้แว่นขยาย
7. เปิด `bad_size_package` และ `bad_exif_package` → ต้องขึ้นหน้าต่างสีแดง "หยุด" และไม่แสดงภาพ

บน iPad: Apple Pencil แตะ/ลาก = วางจุด · นิ้ว = เลื่อน/ซูม · ถ้าไม่มี Pencil กด "นิ้ววางจุด: เปิด" แล้วกดนิ้วค้าง

**มาตรฐานพิกัด:** แบบ COCO — (0, 0) คือมุมซ้ายบนของพิกเซลแรก, กึ่งกลางพิกเซล (i, j) อยู่ที่ (i+0.5, j+0.5) · ใช้กับ OpenCV ให้ลบ 0.5 (รายละเอียดใน [DECISIONS.md](DECISIONS.md))

```powershell

# ชุดทดสอบจริง 70 ราย จาก splits.csv (วางไว้ที่รากโปรเจกต์ · อยู่ใน .gitignore):
python -I -X utf8 -B tools/check_splits.py                                    # 1) ตรวจไฟล์แบ่งชุด (อ่านอย่างเดียว)
```

### ครั้งแรก (ทำครั้งเดียว)

1. เปิดจาก **ไอคอนบนหน้าจอโฮมเท่านั้น** (ไอคอนกับ Safari เก็บงานแยกกัน ถ้าสลับไปมางานจะไม่ต่อกัน)
2. หน้าแรกจะบอก "ทำแล้ว x/N งาน · บันทึกล่าสุด · สำรองล่าสุด"
3. กด **เลือกไฟล์ทั้งหมด** → **เลือกไฟล์** (ไม่ใช่คลังรูปภาพ) → เข้าโฟลเดอร์แพ็กเกจ → **เลือก** (มุมขวาบน) → **เลือกทั้งหมด** → **เปิด**
4. เว็บจะกลับไปที่งานล่าสุดเอง

### การมาร์กจุด
- **Apple Pencil:** แตะใกล้จุด → แว่นขยายขึ้นที่มุมช่อง → ค่อย ๆ ลากให้กากบาทสีตรงจุดที่ต้องการ → ยกปากกา
- **นิ้ว:** กดปุ่ม **"นิ้ววางจุด"** ให้เป็น **เปิด** → กดนิ้วค้างครู่หนึ่ง → แว่นขยายขึ้น → ค่อย ๆ ขยับ → ยกนิ้ว
- นิ้วเดียวลาก = เลื่อนภาพ · สองนิ้ว = ซูม · ช่องเอกซเรย์เปิดมาที่กรอบเส้นประ (บริเวณเดียวกับภาพฟลู)
- วางจุด 1 บนภาพใดก็ได้ → วางจุด 1 บนอีกภาพ → ต่อด้วยจุด 2, 3, 4 (ขอบช่องที่ต้องวางจะเป็นสีของจุด)
- เลือกจุดที่ชัดและไม่เปลี่ยนรูปตามมุมถ่าย เช่น ขอบรูกระดูก ปลายสกรู มุมแผ่นโลหะ · เห็นชัดทั้งสองภาพ · กระจายทั่วกรอบ
- ปรับจุด: ลากจุดเดิม · ลบ: แตะจุดแล้วกด **ลบจุด** · **↶ ย้อน** = ยกเลิกการกระทำล่าสุด
- ครบ 4 คู่ → **ถัดไป** · หาได้แค่ 3 คู่ → **ถัดไป** แล้วเลือกเหตุผล · มาร์กไม่ได้ → **มาร์กไม่ได้** แล้วเลือกเหตุผล (มีตัวเลือก **มุมถ่ายต่างกันมาก**)
- ปุ่ม **หมายเหตุ** (แถบคำแนะนำด้านขวา) = ข้อสังเกตสั้น ๆ ต่องาน ไม่บังคับ · ห้ามใส่ชื่อ/HN

### สำรองข้อมูล (ทุก 10 งาน เว็บจะขึ้นหน้าต่างเอง)
1. กด **บันทึกไฟล์สำรองลงแอปไฟล์** → **บันทึกไปยังไฟล์** → **บันทึก** (ได้ไฟล์ .json ไฟล์เดียว · หาภายหลัง: แอปไฟล์ → ล่าสุด หรือค้นหา `marks_`)
2. ถ้าไม่มีปุ่มนั้น ให้กด **ดาวน์โหลดไฟล์สำรอง** → ถ้าขึ้นหน้าแสดงไฟล์: กดปุ่มแชร์ → **บันทึกไปยังไฟล์** → **บันทึก** → กด **เสร็จสิ้น** เพื่อกลับมาที่เว็บ
3. ถ้ากลับมาแล้วเว็บขึ้น **"ต้องเลือกไฟล์แพ็กเกจอีกครั้ง"** → กดปุ่มนั้น แล้วเลือกไฟล์ทั้งหมดในโฟลเดอร์แพ็กเกจเดิม (**งานที่ทำไว้ไม่หาย** เว็บจะกลับมาที่งานเดิม)
4. "เลื่อนไปก่อน" ได้ 1 ครั้ง ครั้งถัดไปต้องสำรอง

### จบการทำงานแต่ละรอบ
1. กด **จบงาน** → สำรองไฟล์ (ขั้นตอนเดียวกับด้านบน) → กลับหน้าแรก ปิดแอปได้
2. ส่งไฟล์สำรองล่าสุด (`marks_..._<งานที่ทำ>of<ทั้งหมด>.json` หาในแอปไฟล์ → ล่าสุด) ให้ทีม _(ช่องทางรอสรุปกับอาจารย์)_

### ถ้ามีปัญหา
- มุมขวาบนขึ้น **"กำลังบันทึกใหม่…"** = ปกติ เว็บลองบันทึกซ้ำเอง (เกิดได้หลังสลับแอป)
- ขึ้น **"บันทึกไม่สำเร็จ!"** สีแดงค้าง → กด **ส่งออก** → สำรองไฟล์ทันที แล้วแจ้งทีม
- เปลี่ยน iPad / ข้อมูลหาย → หน้าแรก → **นำเข้าไฟล์สำรอง** → เลือกไฟล์ .json ล่าสุด → ถ้าถาม เลือก **รวม**
- หน้าต่างสีแดง **"หยุด"** ตอนเปิดภาพ → ห้ามมาร์กงานนั้น ถ่ายภาพหน้าจอส่งทีม
- ส่งข้อมูลให้ทีมแก้ปัญหา: กด **ดีบัก** มุมขวาบน → ถ่ายภาพหน้าจอ
